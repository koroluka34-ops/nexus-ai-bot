# NEXUS GAME AI — Minecraft

Первый игровой адаптер NEXUS AI. Работает как отдельный Minecraft Java-бот через Mineflayer.

## Что умеет текущая версия

- Подключаться к Minecraft-серверу.
- Получать игровые данные: координаты, здоровье, голод, игроков, ближайшие сущности и блоки.
- Самостоятельно выбирать простые действия через Groq.
- Идти за указанным игроком, перемещаться к ближайшей точке, смотреть на игрока и писать в чат.
- Останавливаться при ошибке и по команде владельца.

Это ранний MVP, а не полноценный универсальный игровой интеллект. Он пока НЕ умеет самостоятельно добывать ресурсы, крафтить, строить или сражаться. Восприятие основано на структурированных данных Minecraft, а не на анализе скриншотов.

## Настройка Render Environment

Добавить:

| Переменная | Значение |
|---|---|
| MC_HOST | skyyforge.falix.pro |
| MC_PORT | 20508 (проверь порт в Falix) |
| MC_VERSION | 26.3 |
| MC_USERNAME | NEXUS_AI |
| MC_OWNER | Edison0009 |
| MC_AUTH | offline |
| MC_CONTROL_USER_ID | твой Telegram ID из /gameid |

Если сервер использует EasyAuth, после регистрации аккаунта игрового бота можно задать MC_LOGIN_COMMAND, например /login ПАРОЛЬ. Пароль вводить только в Render Environment, никогда в Telegram или GitHub. Используй отдельный пароль, не совпадающий с другими.

Если сервер требует лицензионную Microsoft-аутентификацию, offline-вход не сработает. Не пытайся обходить whitelist, авторизацию или серверные правила. Добавь ник бота в whitelist, если он включён.

## Команды Telegram

- /game — справка
- /gameid — узнать свой Telegram ID
- /gameconnect — подключить бота
- /gamestatus — статус
- /gameobserve — описание окружения
- /gamefollow Edison0009 — следовать за игроком
- /gamestart Исследуй окрестности — автономный режим
- /gamestop — остановить автономию
- /gamedisconnect — отключиться

Управление закрыто, пока MC_CONTROL_USER_ID не совпадает с Telegram ID пользователя.

## Ограничения хостинга

Render Free может останавливать веб-сервис после периода без входящих HTTP-запросов. В таком случае игровой бот отключится. Для непрерывной игры нужен постоянно работающий процесс (например, собственный компьютер или подходящий хостинг). Не запускай два экземпляра с одинаковым игровым ником одновременно.

## Протокол Minecraft 26.3

Используется пакет @wp2508/mineflayer, заявляющий поддержку 26.3, и mineflayer-pathfinder. Это сторонний форк, а не официальный upstream Mineflayer. Совместимость именно с конфигурацией SKYFORGE должна быть подтверждена реальным тестом подключения; код не считается проверенным до успешного входа в игру.

## Безопасность

- В текущем MVP агент не ломает и не ставит блоки.
- Агент не атакует игроков и не выполняет команды сервера.
- Разрешены только ограниченные действия: wait, follow, look, say, explore, stop.
- Остановить автономию: /gamestop; отключить: /gamedisconnect.


## Автономное развитие

Цель следующего этапа — самостоятельное выживание: оценка потребностей, выбор собственных задач, сбор базовых ресурсов, изготовление инструментов, исследование и безопасное поведение. Текущий агент пока не реализует полный цикл жизни и не должен считаться готовым автономным игроком.
