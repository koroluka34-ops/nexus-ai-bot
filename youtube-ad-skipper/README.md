# NEXUS YouTube Ad Skipper

Небольшое расширение для Opera GX и других Chromium-браузеров.

## Установка в Opera GX

1. Открой Opera GX.
2. В адресной строке открой `opera://extensions`.
3. Включи «Режим разработчика».
4. Нажми «Загрузить распакованное расширение».
5. Выбери папку `youtube-ad-skipper` из этого репозитория (в ней должны лежать `manifest.json` и `content.js`).
6. Открой или обнови вкладку YouTube.

Расширение работает только на страницах YouTube. Оно ждёт появления активной кнопки пропуска во время рекламы и нажимает её. Если реклама не поддерживает пропуск, расширение не может её убрать.

## Ограничения

- Расширение не блокирует рекламу и не пропускает непропускаемые рекламные вставки.
- Оно не отправляет данные и не требует специальных разрешений.
- Это отдельное расширение браузера: Windows Agent и Render для его работы не нужны.
